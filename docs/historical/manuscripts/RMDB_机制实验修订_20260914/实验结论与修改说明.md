# 本轮实验结论

已完成 1,960 张 mBRSET 图像和 100 张 Fundus 图像的十方案比较。历史 raw/mass/joint/smooth/cleanup 与新增固定混合、身份置信度约束和等更新量对照统一汇总，共 19,600 个重复性图像—方案记录和 1,000 个结构图像—方案记录；其中历史控制复用，不能称为全部重新推理。

## 真实发现

- 占据重新加权引入了视图间 A/V 比值波动；历史 test 的平方 log 配对误差增加 0.02059 [0.01571, 0.02592]。这是输出误差分解，不是对相机、照明等原因的因果证明。
- 固定混合可以减轻完全条件化的损害，但没有消除权衡，不从 test 选最佳 α。
- 身份置信度约束未通过等更新量对照：A/V MAD 差 0.003406 [0.002552, 0.004333]，Dice 差 -0.001163 [-0.001661, -0.000628]，细中心线召回差 -0.007331 [-0.007926, -0.006758]。因此不把该模块升级为推荐模型。
- 所有十二项指标和阴性结果保留。独立统计复算通过 2,160 项检查，480 项历史点估计完全一致。

## 论文修改

新增方法 2.9、结果 3.5、补充表 S4–S8；修改摘要、贡献、讨论、局限与结论。旧六张数值表保留。新 bootstrap 为 5,000 次，不覆盖原来的 10,000 次区间。图中原始架构未增加未获支持的“成功模块”。

## 尚未完成

没有新独立高分辨率跨相机重复队列；没有当代工具的匹配全流程比较；没有重新训练残差特征组消融。本轮未训练新网络。全体数据此前已被分析，因此本轮全部是探索性后续实验。当前结果加强了机制证据和基线完整性，但不能据此声称强算法创新或已具备临床转化证据。

## 决策

执行预先记录的停止条件，不继续根据本轮 test 寻找更好门控。保留现有双读出模型；以机制解释和严格控制实验修订论文，不伪装成新的成功算法。完整对照、置信区间和变异度结果见实验结果文件夹。
