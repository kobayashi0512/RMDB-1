## 结果索引

- `实验结果/repeat_per_image.csv`：全部 1,960 张图像、10 个方案、12 个特征。
- `实验结果/fundus_per_image.csv`：100 张标注图像、10 个方案的结构指标。
- `实验结果/repeat_estimates.csv`：开发与历史测试子集的 ICC、MAD、SEM、LoA 和变异度。
- `实验结果/repeat_contrasts.csv`：各方案相对 raw 的配对差异。
- `实验结果/new_method_paired_contrasts.csv`：置信度方案相对等更新量、完全条件化和固定混合的配对差异。
- `实验结果/new_method_structural_contrasts.csv`：相应结构差异。
- `实验结果/mechanism_pairs.csv`：逐眼 log 比值误差分解。
- `实验结果/mechanism_pair_estimates.csv`：患者聚类 bootstrap 的分解汇总。
- `实验结果/audit.json`：独立点估计复核与源哈希检查。

每张图像的几何、概率和预算核对记录位于原项目的 `artifacts/readout_mechanism_20260914_v2` 与 `artifacts/readout_confidence_20260914_v1`。历史六张数值表保留在原 DOCX；本轮新表不替换旧 bootstrap 区间。
