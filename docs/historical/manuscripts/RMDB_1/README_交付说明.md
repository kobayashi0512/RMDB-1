## 唯一主线

在冻结 VascX 骨干与统一表型提取算子的条件下，比较两类并行读出如何改变结构保真度与同眼测量一致性，揭示终点依赖的权衡。

残差校正与占据条件化不是串联网络，不做概率融合；每个读出分别与原始概率比较。A/V 重加权分解用于解释响应，等更新预算控制与短程重训练用于检验设计假设，它们服务于同一主线，不是三套独立故事。
