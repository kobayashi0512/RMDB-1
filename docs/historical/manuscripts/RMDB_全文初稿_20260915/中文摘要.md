# RMDB：面向视网膜血管测量的双读出方法

视网膜血管测量不仅取决于分割概率，还取决于如何将这些概率转换为图像表型。本研究围绕冻结的 VascX 表示构建两种并行读出：对身份 logits 进行残差修正，以及结合独立血管占据概率与原始条件动脉、静脉和交叉身份的占据条件化。在共同表型算子下，采用100张 Fundus-AVSeg 图像评价结构，采用历史 mBRSET 测试子集中255名患者的475只重复拍摄眼评价一致性。全部12项表型联合报告 ICC、眼内平均绝对偏差、池化眼内标准差及一致性界限。历史残差修正使血管 Dice 从0.8556提高至0.8647，细中心线召回从0.7971提高至0.8365，但精确率从0.9396降至0.9096。占据条件化使9项表型的 ICC 点估计提高，其中分支密度、端点密度和占据熵同时具有支持 MAD 减少的区间；A/V 概率质量比的 ICC 则从0.5340降至0.3639，MAD 增加44.72%。输出误差分解解释了局部身份保留与全局 A/V 变化为何可以并存。等更新量控制与七组三种子残差重训练均未确立普遍占优的干预。研究支持按具体终点评价读出设计，不构成临床准入或独立跨相机验证。

关键词：视网膜血管；概率读出；动静脉分割；血管测量；重复性；测量一致性。
