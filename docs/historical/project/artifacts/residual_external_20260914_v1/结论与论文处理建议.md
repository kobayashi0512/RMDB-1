# 联合评估后的决策

## 核心判断

这轮新完整网络没有显示可以替换旧主模型的整体优势。证据支持的是“结构恢复与测量重复性存在终点特异的取舍”，不是“复杂新网络解决了取舍”。既有主模型和旧论文结果保持不变。

## 有增量的发现

1. **结构收益真实存在，但有代价。** 三种子平均血管 Dice：raw 0.855552、旧 mass 0.864662、新完整网络 0.872339。新完整网络相对旧 mass 的 Dice 差为 +0.007677，探索性 95% 区间 [0.004508, 0.009996]；同时 Precision 差为 -0.014320 [-0.022104, -0.006332]。端点密度参考误差也增加，不能把它概括为全面结构改进。
2. **结构收益没有自动转化为重复性收益。** 历史 test 中，新完整网络相对 raw 的血管质量、动脉质量、静脉质量、血管密度和分支密度，同时出现 ICC 差区间低于零、MAD 差区间高于零。所有比较未经多重性调整，属于探索性方向证据。
3. **ICC 单独变高可以误导选择。** 连通分量计数 ICC 差 +0.079346 [0.003822, 0.160005]，但 MAD 差也为 +0.390175 [0.123858, 0.684608]。ICC 数值更高，不等于两次测量更接近。这是本轮对“必须联合报告绝对一致性”的具体支持。
4. **A/V MAD 的点估计改善不能直接算成功。** 原始 VascX 的 ICC/MAD 为 0.534033/0.028891，新完整网络为 0.495159/0.025770。MAD 差 -0.003122 [-0.005608, 0.000301]，区间跨零；眼均值 SD 从约 0.066432 降到 0.056498，缩小约 15%。需警惕读数范围收缩，不能据此断言生物差异保留或测量可靠性提升。
5. **尚未证明复杂结构不可替代。** 新完整网络与普通卷积的结构 Dice 差异未形成明确区间优势；两步与重训练单步之间也未证明两步更优。旧冻结权重截断时第二步有结构作用，并不等于“重训练单步模型一定更差”。无明确差异也不是等效或非劣证明。

## 论文应如何处理

- 保留“separates/exposes the trade-off”的主结论，不改回“resolves”。
- 将本轮作为受控反例与测量方法学证据：展示结构提升、重复性代价，以及 ICC 与 MAD 方向不一致的实例。
- 不把新完整网络包装成新的推荐算法；不挑某个种子或消融版本作为 test 上的赢家。
- 不把“修正 RAV 训练标注几何”直接写成性能改善的唯一原因。新旧训练配方、种子和训练选择等同时不同，旧 mass 配置仍不完整，无法作这种单因素因果归因。
- 正文修改应基于本轮已冻结结果单独追加，不能覆盖旧主表或混合不同 bootstrap 设置。当前只交付实验结果和解释，尚未改写 Word 正文或 PPT 架构图。

## 当前不启动的动作

不继续根据这批已分析的外部数据调门控、加层或选最优模型。下一步宜整合证据与收敛论文贡献；如仍要追求强算法创新，需要另立开发目标与未参与选择的确认数据，而不是在这些结果上继续搜索。

## 证据边界

全部数据均已被历史分析使用；mBRSET 为 224 像素公开镜像。两个队列不能证明同一患者的结构准确性与重复性共同提高。新权重来自默认损失、3 epoch 的探索性重训练，不是旧 mass 校准配方的精确复现。缺少独立高分辨率重复队列、临床容差与测量参考、当代工具全流程匹配比较等问题仍未解决。
