# 固定权重外部联合评估

| 问题 | 固定比较 | 主要证据 | 边界 |
|---|---|---|---|
| 新读出是否恢复更多结构 | 21 个固定模型分别对 raw、旧 mass | Fundus 100 张的 Dice、Precision、细中心线召回、clDice，以及 6 项结构参考误差 | 不以 Dice 一项作为成功标准 |
| 新读出是否更稳定 | 同图像、同视野、同测量算子 | mBRSET 两个历史子集的 ICC、MAD、SEM、LoA、眼间离散度 | 224 像素镜像；不是新的高分辨率确认 |
| 显式输入和两步结构是否必要 | 每个种子下消融对完整网络 | 相同样本与更新预算下的配对差 | 相关信息仍可经其他路径进入；无差异不等于等效 |
| 结构与稳定性是否同时提高 | 按同一模型组分别展示两个队列 | 各终点方向和区间全部保留 | 不同队列，不能作患者内准确性—重复性关联结论 |
| 是否已达到临床可用 | 本轮不作通过判定 | 尚缺临床容差、独立队列及测量参考 | 不宣称临床 gate PASS |

每个权重固定为上一轮第 3 个 epoch，不选验证集最佳 epoch，不增加训练。新方法组的汇总是三个独立模型的指标均值，不是概率集成。训练集固定，重采样区间不覆盖更换训练队列带来的全部不确定性。

所有新旧模型采用同一 512 概率网格、RGBmax>10 视野、血管概率边缘和阈值 0.5、256 骨架网格。旧 mass 已审计的逐图控制值复用，raw 本轮重新计算并核对；不能把全部 47,380 条记录称为重新推理。

完整新权重推理为 21×(1,960+100)=43,260 个图像—权重组合。每个种子独立保存数值，再用配对患者/图像与种子重采样汇总；不挑选某个有利种子。

## 复现命令

在原实验项目根目录，使用现有环境执行：

```sh
.venv/bin/python src/evaluate_residual_ablation_external.py prepare
.venv/bin/python src/analyze_residual_ablation_external.py prepare
.venv/bin/python src/audit_residual_external.py preflight
.venv/bin/python src/evaluate_residual_ablation_external.py fundus
.venv/bin/python src/evaluate_residual_ablation_external.py repeat
.venv/bin/python src/analyze_residual_ablation_external.py fundus
.venv/bin/python src/analyze_residual_ablation_external.py repeat
.venv/bin/python src/screen_residual_external_overlap.py
.venv/bin/python src/audit_residual_external.py run
.venv/bin/python src/report_residual_external.py
```

逐图结果采用原子写入，可以恢复未完成批次。协议和源代码哈希不匹配时拒绝续跑；需要修改研究设置应创建新版本，不覆盖本轮记录。

全部三种子的点估计和条件重采样区间在 `*_seed_estimates.csv`；三个独立模型的均值和交叉重采样区间在 `*_group_estimates.csv`；所有预定配对比较在 `*_group_contrasts.csv`。IQR 仅报告点估计，不提供伪造的区间。LoA 仅使用前两张清单顺序图像，不假定时间先后。

患者级独立确认、VascX 全部预训练集重叠审计、当代工具全流程比较和临床有效性均不在本轮已经完成的证据范围内。原论文、旧权重和旧数据不被本轮覆盖。
