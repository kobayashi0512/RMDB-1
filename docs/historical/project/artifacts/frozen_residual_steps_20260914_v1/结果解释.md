# 原冻结残差模型：一步与两步

在既有 100 张 Fundus 图像上，固定旧权重、输入和已校正的标注几何，只改变执行的残差步数。此次不是新模型训练，也不是独立确认。

| 读出 | 血管 Dice | Precision | 细中心线召回 |
|---|---:|---:|---:|
| raw | 0.855552 | 0.939635 | 0.797114 |
| 第一步后 | 0.861476 | 0.925437 | 0.818377 |
| 第二步后 | 0.864662 | 0.909626 | 0.836480 |

第二步相对第一步：

- Dice 增加 0.003186，配对 95% 区间 [0.002616, 0.003730]。
- 细中心线召回增加 0.018103，区间 [0.017518, 0.018714]。
- Precision 降低 0.015811，区间 [-0.016197, -0.015452]。

这支持“第二步进一步促进血管恢复，同时引入额外误检”，不支持“两步在所有意义上更好”。Dice 与 Precision 的变化不能单独替代测量重复性证据。

raw 与完整两步结果均复现历史结构表，最大点估计差为 1.11e-16。完整 5 个结构指标、逐图结果和所有配对区间都保留在同目录 CSV 中。

统计采用 5,000 次图像配对重采样，随机种子 20260918；区间未作多重比较调整，均为探索性。第一步是对两步训练模型的推理截断，不等于单步重新训练。因此应与新协议重训练实验分开解释。
