# 本轮结论：机制证据增加，算法优势尚未成立

## 已完成的实际工作

- 7 个方案 × 3 个种子，共 21 次受控重训练；每次 3 个 epoch、270 次优化更新，全部最终权重保留。
- 核验 206 张 RAV 图像的裁剪几何，为 87 张受影响标注生成独立对齐版本；原数据未覆盖。
- 普通卷积对照参数量与完整网络相差约 2.2%，但卷积 MAC 约为完整网络 4 倍。因此是近参数量对照，不是等计算量或效率比较。
- 另在 100 张 Fundus 图像上完成原冻结权重的一步/两步检查，复现原 raw 和两步结构结果。

## 结果意味着什么

1. **本轮完整重训练模型未显示 A/V Dice 优势。** 验证集三种子平均 A/V Dice：完整网络 0.782053，raw 0.789850；配对差 -0.007797，探索性 95% 区间 [-0.012914, -0.002858]。历史相机 7 张的平均差为 -0.002531，区间 [-0.010311, 0.003777]，不支持确定的方向性结论。
2. **不能把它说成“所有能力都变差”。** 有类型标注像素上的预测正确率提高：验证集差 +0.048446 [0.041981, 0.055031]；历史相机差 +0.042622 [0.027865, 0.057760]。该指标把预测为背景也算错误，不是“仅在已检测血管中”的纯身份准确率。它与 Dice 的分歧需要分别解释。
3. **目前没有证明额外特征或两步结构不可替代。** 六个变体相对完整网络的平均 A/V Dice 区间，在两个子集中均跨零。这是证据不足，不是已经证明等效，也不是证明所有特征无用。显式输入被遮蔽时，相关信息可能仍经基准概率或损失进入网络。
4. **原冻结权重的第二步确实有结构作用，但仍有代价。** 第二步相对第一步使 Dice +0.003186、细中心线召回 +0.018103，同时 Precision -0.015811。详见旁边的 `frozen_residual_steps_20260914_v1` 目录。

## 对论文与继续探索的决策

保留现有冻结双读出主模型；不以这批新权重替换，不把本轮包装成“算法创新突破”。旧论文数值没有被这些新实验覆盖。

这批实验的正确定位是：新训练协议下的短程、探索性机制检验。它显著加强了对照和流程审计，但还没有找出一个更强的新模型。

下一步优先做固定新权重的外部结构—重复性联合评估，并进一步核对原训练配方；再决定是否值得延长训练或研发新约束。不能凭这 7 张已看过的相机留出图继续调参，也不能把固定 3 个 epoch 的结果当作充分收敛结论。当前不启动额外门控搜索。

旧 mass 校准模型缺完整训练配置；新协议的两项附加 mass 损失权重明确为 0，因此不能称为旧校准配方的直接消融。缺患者标识、独立高分辨率重复队列和新权重的完整 ICC/MAD/SEM/LoA 评估，仍是证据边界。
