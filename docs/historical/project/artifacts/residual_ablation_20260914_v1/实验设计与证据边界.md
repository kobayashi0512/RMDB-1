# 残差设计贡献：新协议受控实验

本轮按实验设计审查要求，先修正输入几何、固定协议，再运行；不以论文写作为先，不根据历史 test 选模型。

| 待检验的问题 | 固定对照 | 能回答什么 | 不能回答什么 |
|---|---|---|---|
| 显式 RGB 输入是否有贡献 | full 与 no_rgb | 其他路径不变时的输入增量 | 图像信息是否完全不需要；logits 与 Hessian 本身来自图像 |
| 显式初始 logits 输入是否有贡献 | full 与 no_logit_input | 静态 logits 通道的增量 | VascX 是否不需要；基准 logits 与迭代概率仍保留 |
| 显式熵通道是否有贡献 | full 与 no_entropy_input | 熵输入的增量 | 是否移除了所有不确定性信息；概率和损失仍含相关信息 |
| Hessian 输入是否有贡献 | full 与 no_hessian_input | 方向/强度输入的增量 | 是否移除了方向正则化；损失不随输入消融改变 |
| 第二次迭代是否有贡献 | full 与 one_step，另做原权重截断 | 同参数、同优化步数的迭代对比；原权重第二步的实际变化 | 计算量相同的优越性；冻结截断不等于重训练单步 |
| U 型结构是否胜过简单卷积 | full 与 plain_conv | 近参数量、同样本与优化步数下的结构比较 | FLOPs 或推理成本匹配的优越性 |

## 关键缺口与优先级

1. 高：旧 mass 校准训练配置缺失。本轮只用已存在训练代码的明确默认损失，因此属于新协议机制实验，不是旧配方的精确消融。旧权重仅保留为单独冻结参照。
2. 高：历史相机留出仅 7 张，且已被分析；不能称独立确认。RAV 元数据没有患者标识，图像去重不等于患者独立。
3. 高：新权重尚未做完整结构—重复性联合评估；RAV 分割不能替代 ICC/MAD/SEM/LoA。
4. 中：3 个种子、每次 3 epoch 是固定短程预算，不保证收敛。所有结果均报告，不拿最佳 seed 或 epoch 当主结果。
5. 中：参数量匹配不等于计算量匹配；计算审计另存，不据本轮做效率宣称。

## 文件与复现

所有命令在实验项目根目录执行，使用现有 `.venv/bin/python`：

```sh
.venv/bin/python src/prepare_residual_ablation.py
.venv/bin/python src/test_controlled_residual_ablation.py
.venv/bin/python src/train_controlled_residual_ablation.py smoke
.venv/bin/python src/train_controlled_residual_ablation.py prepare
.venv/bin/python src/report_controlled_residual_ablation.py prepare
.venv/bin/python src/train_controlled_residual_ablation.py train
.venv/bin/python src/audit_residual_ablation_inputs.py
.venv/bin/python src/report_controlled_residual_ablation.py report
.venv/bin/python src/evaluate_frozen_residual_steps.py
```

训练阶段按完整 epoch 保存模型与优化器，可续跑。协议和源代码哈希漂移会拒绝继续；更改实验需新版本目录。请勿覆盖既有模型或把 smoke 结果当科学证据。

原始标注、缓存和旧论文结果均未覆盖；新的几何对齐标注独立放在 `aligned_masks`。训练结果保存于 `runs/方案/种子/`，不自动写入论文或替换主模型。
