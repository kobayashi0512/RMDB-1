# 血管结构约束残差恢复原型

本轮用于检验“学习式恢复能否在固定分割器上超过 CLAHE，并避免结构测量损伤”，不是最终投稿模型。

## 已实现

输入退化 RGB → 小型编码解码网络（16/32/64 通道，跳跃连接）→ 受限 RGB 残差 → 与输入相加 → 冻结 VascX → 分割与比例评价。

- 输出为 `clip(input + 0.25 × tanh(residual) × field, 0, 1)`。
- 最后一层零初始化，初始网络严格等价于原图通路。
- FIVES 原图和血管二值标注只来自原开发划分，480 张训练、120 张验证。
- 配对参考是原始采集图像，不称为绝对清晰真值。合成退化不改变图像几何。
- 对照网络仅优化 RGB 重建 MAE。
- 结构网络增加血管区域重建 MAE、血管区域水平/垂直图像梯度保持。
- 两网络的架构、初始化、训练输入、轮次、优化器一致；只改变损失。
- 25% 概率提供未人工退化的训练输入，防止无条件增强。
- 20 个真实训练轮次，每轮遍历全部 480 张图像，各随机抽取一个192像素patch。
- RAV 30 张既有开发验证图像只在检查点冻结后做一次固定对照，不用其结果选参数。

## 未实现及不能声称的内容

- 没有从不可恢复区域“生成真实细血管”的保证。
- 图像梯度约束不是拓扑证明，也不等同于 clDice。
- FIVES 无动静脉身份标注，本轮没有动静脉监督损失；只在 RAV 上评价身份和比例是否受损。
- 没有扩散生成、真实拍摄低清/高清配对监督，也没有已发表增强模型的全面复现。
- 同架构普通重建网络是消融基线，不替代 Cofe-Net、MAGE-Net 等文献方法对照。
- 不能因均值改善就宣称独立外部或临床确认。不能与错误坐标的0.55比较。

## 队列

`src/structure_restoration_pilot.py`：准备数据、并列训练两种模型、按相同验证准则保存检查点。

`src/evaluate_structure_restoration_pilot.py --training-pid <pid>`：等待训练成功标记后自动开始240个冻结分割推理，汇总预定义对照，执行全部有限输出核查。

`src/test_structure_restoration_pilot.py`：回归检查初始化、残差幅度、背景旁路、梯度、退化随机性、划分隔离。

## 停止条件

所有固定比较完成后，若主Dice收益及精确率、比例、原图安全性守则未全部通过，则停止本轮分支并报告负结果，不利用 RAV 或 Fundus-AVSeg 反复调整。
