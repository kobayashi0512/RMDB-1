## 本阶段反思

1. **独立复现通过，但绝对性能仍不高。** 算法改善是真实且一致的，
   不能掩盖 mean A/V Dice 约 0.56 的事实。
2. **比例守恒 UDCT 优于硬因子化。** 硬占据阈值会删除部分真实细血管，
   因而门控模型仅取得较小 Dice 增益；四分类残差仍保留了更多原始血管证据。
3. **两个读出具有不同优势。** 比例守恒 UDCT 最适合 A/V 身份和像素重叠；
   门控模型的 A/V比例误差最低，适合作为质量控制及稳健性辅助读出。
4. **不得在 Fundus-AVSeg 上继续调参。** 当前分层结果用于定位问题，
   不能据此重新选择阈值后仍称为外部验证。
5. **下游应保留双读出而非强行二选一。** 主表型来自比例守恒 UDCT 的软概率；
   门控占据输出用于拓扑/几何及两模型分歧度；分歧度作为患者级可靠性变量。
6. **DR 与低质量是明确的失败域。** 后续若训练域扩展，必须在新的开发数据上进行，
   并另找第三数据集确认，不能回头优化本外部测试集。

## 下一步决策

外部复现门槛已经通过，可以进入 CIMT 开发队列的双读出表型生成：

1. 为每眼输出比例守恒 UDCT 软 A/V 概率；
2. 输出门控占据—身份分割；
3. 计算血管覆盖、A/V软质量比、分支/长度/曲率、模型分歧和不确定性；
4. 先在患者级训练/验证折中做增量价值实验；
5. 继续隔离 CIMT 测试集，直至模型、特征和统计方案全部锁定。
